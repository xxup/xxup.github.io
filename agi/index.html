项目简介

本站是 AGI（Alliance Graphique Internationale）会员作品展示墙，以瀑布流方式浏览会员的设计作品，支持搜索、筛选、收藏与深色模式。

使用说明

  • 搜索：支持标题、设计师、客户、标签等关键词；可叠加年份、国家、类型筛选。
  • 发现：按设计师 A-Z、年份、国家三种维度浏览作品。
  • 收藏：灯箱左上角 ♥ 收藏作品，收藏保存在浏览器本地（localStorage），换设备不同步。
  • 深色模式：抽屉左上角太阳 / 月亮图标切换。
  • 键盘：← → 切换灯箱图片，Esc 关闭灯箱 / 抽屉 / 搜索。
  • 手势：灯箱内双指缩放、双击放大，放大后可拖动。
